1. 목표

전 지구 앙상블 기후예측 모델의 원자료를 한반도 육상 0.5° 격자(118개 지점)에서 가공하여, 1개월(주별 1–4주)과 3개월(월별·계절) 전망을 사람의 주관 없이 일관된 절차로 산출·표출한다. 모든 결과는 결정론적 값이 아니라 확률로 제공한다.

  • 요소: 평균기온, 강수량, 일사량(단파복사), 10 m 풍속
  • 표출: 3분위 확률, 평년(중앙값) 초과확률, 앙상블 평균, 평년편차, 임계값별 발생확률, 극한(상·하위 10%) 확률, 앙상블 스프레드
  • 지도에서 지점을 클릭하면 별도 창에 시계열(앙상블 분포), 기간별 멤버 분포, 통계표(CSV)를 표출

4. 산출 방법

  1. 기간 집계 — 멤버별 일별값을 예측 기간(주·월·계절)으로 집계한다. 강수는 누적, 기온·일사·풍속은 평균. 1개월 전망의 주는 월요일 시작–일요일 끝이며, 1주는 발표일 다음 주 월요일의 그다음 주부터다(예: 10/29(목) 발표 → 1주 11/9–11/15, 4주 11/30–12/6).
  2. 모델 평년값 — ECMWF가 재예측으로 계산한 주/월 편차 a와 평균 A를 이용해 모델 기후값을 역산한다.
    기온(가법): 평년 = 앙상블평균 − a   |   강수·일사·풍속(승법): 평년 = 앙상블평균 × (A − a) / A
    승법 방식은 API의 월별 단위(일평균/월합계)와 무관하게 성립한다. 4주·3개월 전체 평년값은 구성 기간 평년값의 합(누적) 또는 일수 가중평균. 1개월 전망의 강수·일사·풍속은 EC46 주별 평균의 정의(멤버 수·집계 방식)가 일별 멤버 집계와 달라 비율 역산이 불안정하므로, 같은 IFS 계열인 SEAS5의 월별 모델 기후값을 일 단위로 환산하고 월 중앙일 사이를 선형 보간(월 안의 계절 변화 반영)하여 주 기간에 합산(강수)·평균(일사·풍속)한다. 기온은 EC46 주별 편차를 그대로 쓴다. 모델 기후값을 구할 수 없으면 ERA5 평년값을 사용하고 표에 E로 표시한다.
  3. 평년 분포 — ERA5 1991–2020의 같은 달력기간 30년 집계값으로 10·33.3·50·66.7·90% 분위수를 구하고, 기온은 분위수 − 평균, 나머지는 분위수 / 평균 형태로 바꿔 모델 평년값에 적용한다(대표 지점 → 격자 역거리가중 보간). ERA5 캐시가 없으면 정규(기온)·로그정규(그 외) 분포와 기본 변동폭을 가정한다.
  4. 확률 — 51개 멤버 중 조건을 만족하는 멤버의 비율.
    P(낮음) = #(X < 하위 1/3 경계)/N,   P(높음) = #(X > 상위 1/3 경계)/N,   P(비슷) = 1 − P(낮음) − P(높음)
    중앙값 초과, 상·하위 10%, 임계값(기온 편차 ±1·±2 °C, 강수 평년비 50/150/200 %와 누적 강수량, 일사·풍속 평년비 80/90/110/120 %)도 같은 방식.
  5. 지도 표출 — 육상 격자값을 쌍선형 보간하여 메르카토르 이미지로 만들고 한반도 해안선으로 잘라 표출한다. 3분위 지도는 세 확률을 각각 보간한 뒤 화소마다 우세 범주를 정한다(최대 확률 40% 미만은 ‘불확실’).

4-1. 지역 상세화 (기상청 ASOS)

  • 지점 상세화: 기상청 공식 평년 지점 66곳(남한 본토 대표 62곳 + 제주 4곳)의 1991–2020 관측을 쓴다. 대구·전주는 공식 평년과 같이 병합 지점(860 신암, 864 완산) 자료로 2015년 이전 자료를 이어 붙인다. 30년 같은 달력기간 집계로 평년값을 계산하고, 평년 범위는 기상청 방식대로 기온은 평년 ± 0.43σ(표본표준편차), 강수·일사·풍속은 33–67 백분위로 정한다. 주변 0.5° 모델 격자의 멤버별 평년편차(기온) 또는 평년비(강수·일사·풍속)를 역거리가중으로 지점에 보간해 관측 평년에 적용한다. 그러면 관측 기준의 51개 멤버 값이 되고, 3분위·임계값 확률을 관측 분포로 계산한다.
  • 남한 20 km(0.2°) 격자: 지점 평년(기온은 6.5 °C/km 기온감률로 해면 기준 변환)과 분포 형태를 271개 격자로 보간한 뒤 격자 평균 고도로 되돌린다. 모델 신호 적용은 지점과 같다. 지도에서는 남한은 상세화 값, 북한은 0.5° 모델 값을 합쳐 보여 준다.
  • 달력 월은 기상청 공식 범위: 3개월 전망의 1·2·3개월은 지점 평년값으로 기상청 공식 월평년값(1991–2020)을 쓴다. 지도 위 카드에는 남한 본토 62개 지점 평균의 멤버 값을 기상청 공식 월평년 '비슷' 범위로 −/0/+ 3분류한 확률을 따로 보여 준다(기온: 평년 ± 0.43σ, 강수: 33–67 백분위). 1개월 전망의 주·4주 기간과 3개월 전체는 공식 범위표가 없어 30년 관측으로 같은 방식을 적용한다.
  • 한계: ASOS 평균 간격(약 40 km)보다 작은 규모의 지형 효과는 고도 보정 외에는 담지 못한다. 일사는 관측 지점이 적어 보간 오차가 크다.

5. 산출물

지도 (전망 지도)

  • 전망 종류 × 요소 × 기간 × 표출항목 조합
  • 마우스 위치의 보간값 실시간 표시
  • 기간별 비교(소형 다중 지도)로 시간 변화 파악
  • 주요 도시 바로가기, 분석 격자점 표시
  • 주소창 해시(#product=…)로 화면 공유

지점 상세 창

  • 기간별 3분위 확률 막대 + 중앙값 초과확률
  • 일별 앙상블 시계열(최소–최대, 10–90%, 25–75%, 중앙값, ERA5 일평년값), 강수 누적 그래프
  • 기간별 51개 멤버 분포와 평년 범주 경계
  • 통계표: 평균·평년·편차·스프레드·분위수·범주확률·임계값별 확률, EC46 직접 산출 확률·EFI
  • CSV 내려받기, 새 브라우저 창 분리

6. 시스템 구성

서버 없이 동작하는 정적 사이트다. 계산은 모두 배치(파이썬)에서 하고, 브라우저는 산출된 JSON만 읽는다. 매일 산출된 자료와 웹사이트는 gh-pages 브랜치(단일 커밋)에 게시되어 GitHub Pages로 서비스된다. 정기 실행은 매일 07:10 KST(예비 12:10 KST)이며, 지도 자료는 45일간 날짜별로 보관되어 화면의 ‘발표일’ 목록에서 지난 발표를 다시 볼 수 있다.

pip install -r pipeline/requirements.txt
python pipeline/climatology.py     # ERA5 평년 캐시 (최초 1회, 이어받기)
python pipeline/outlook.py         # 전망 산출 → site/data/latest/
python -m http.server -d site 8000 # http://localhost:8000

7. 한계와 향후 계획

  • 보정 미적용: 평균 편의는 모델 기후로 제거하지만 앙상블 퍼짐(신뢰도) 보정은 하지 않았다. 재예측 자료 확보 시 분위수 사상·EMOS 보정 도입.
  • 검증: 과거 예측(재예측)에 대한 RPSS·ROC·신뢰도 도표를 산출해 지도에 예측성(skill) 마스크를 겹치는 것이 다음 단계(BoM의 ‘past accuracy’ 지도에 해당).
  • 해상도: 36 km 모델 · 0.5° 격자로 산악·해안 효과가 약하다. ASOS 지점 기반 통계적 상세화 계획.
  • 다중 모델: C3S 다중모델(UKMO, Météo-France, DWD, NCEP 등) 결합 시 확률 신뢰도가 향상된다.
  • Open-Meteo 무료 API는 비상업용이며 호출량 제한이 있다. 운영 시 상용 키 또는 ECMWF/C3S 원자료 직접 수집 권장.
